# 图形界面使用说明

[English](GUI.en.md)

**本版面向 CubeMX 生成的 STM32 HAL + Keil 工程。** 标准库（SPL）与自定义目录工程
不在自动移植验收范围；请先阅读[适配范围](SUPPORT.zh-CN.md)，不要把添加引用成功当成运行通过。

右上角 `zh-CN / en` 可切换语言并保留文件勾选；底栏“指南”可离线阅读教程。
另见[各组件移植后必做事项](POST-PORTING.zh-CN.md)和[Git 使用教程](GIT.zh-CN.md)。
部分底层诊断与外部工具日志保留原语言。

新版界面使用左侧导航。选择页面只是查看该功能；勾选右上角的「启用此功能」，
才会把它加入本次任务。底部显示已启用功能数量。

## 一次移植的操作顺序

1. 选择 `.uvprojx` / `.uvproj` 工程及目标 Target。操作前关闭 Keil 中打开的工程。
2. 「库仓库」是中间件的源码来源。移植组件使用工程内独立副本，不直接修改共享库。
3. 在左侧进入需要的功能，勾选「启用此功能」，指定源码或点击「自动准备」。
4. 在文件清单里核对具体模块和用途，取消不需要的文件。必需依赖仍会由后台校验。
5. 点击「预览并执行」，检查差异和提示，再确认写入。取消预览不会应用工程修改。
6. 完成后重新加载 Keil 工程，编译并进行对应硬件测试。编译成功不等于驱动已可运行。

「工程文件」页面是给现有文件添加引用，**不是源码复制功能**。
如果是共享目录中的普通 C/H/库文件，请先自行复制到工程内，再扫描该工程目录。
屏幕、网卡、Flash、SD 和 USB 的硬件引脚、时钟及底层驱动仍需匹配实际电路。

## 文件选择

- 蓝色勾：选中；空框：不选；横线：目录内部分选中。
- 单击文件或目录名称，或选中后按空格切换。目录可以整组选择。
- 单击目录左侧展开箭头只展开/折叠，不会改动选择。
- 初次扫描默认全选；再次扫描相同路径保留旧文件的选择，新发现的文件默认选中。
- 清单底部显示已选/总数。预设恢复使用保存的文件清单，不会自动扩大到新增文件。

FreeRTOS 和 RT-Thread 不能在同一工程同时启用；发生冲突时执行按钮会禁用。
FatFS、LittleFS、LwIP 的「RTOS（工程内核）」根据工程选择具体 RTOS 适配，
「自动判断」适合一般场景。旧预设中的 FreeRTOS 模式名称仍可读取。

## 窗口与辅助工具

- 日志在独立窗口中显示，不压缩文件清单。
- 工程设置页可以滚动；键盘焦点会让目标控件进入可见区域。
- 设置、预设、工程工具、安全与恢复位于底部。
- 已检查 980×650、1180×800 布局与 100%/125%/150% 缩放。
- 下载、移植事务、卸载/回滚与 Keil 编译由后台线程执行，日志与确认窗口在主线程显示。
  忙碌期间不允许重入、切换语言或关闭；在差异预览点可以取消，不支持写入中强制中止。
  扫描及大量文件树的显示仍有同步部分，可能短暂停顿。详见[可靠性说明](RELIABILITY.zh-CN.md)。

这是 GUI 指南，不代替各组件接入说明、测试范围和发布说明。
