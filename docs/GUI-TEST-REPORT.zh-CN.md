## 重复运行

```powershell
python tests/test_gui_actions.py
```

默认跳过需要本机 Keil 的用例。先复制一份可构建工程，再显式启用：

```powershell
$env:KPS_REAL_BUILD_PROJECT = 'D:/YourIsolatedTest/MDK-ARM/Test.uvprojx'
$env:KPS_UV4 = 'D:/Keil_v5/UV4/UV4.exe'
python tests/test_gui_actions.py
```

该可选用例会全量构建指定工程并写入其编译输出，请勿指向需要保持不变的归档。
长任务仍同步执行，暂不支持取消正在运行的 Keil 编译。
