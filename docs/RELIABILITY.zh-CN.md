# RC2/RC3 可靠性加固与验证边界

[English](RELIABILITY.en.md)

本轮没有增加新组件。优先修复“看起来成功，实际没有正确接入”和“卸载误改用户代码”的风险。

## 行为变化

- 启动补丁返回明确状态：已修改、已正确接入、不适用、冲突或不支持。关键补丁无法确认时，组件规划失败，整次组合不写入工程。
- SVC/PendSV 只自动接管确认无用户逻辑的空壳；函数里的注释和字符串不再被误认成实际调用。未知条件编译、重复定义或自定义启动控制流可能要求人工适配。这是保守检查，不是完整的 C 解析器或运行正确性证明。
- 安装记录保存实际修改文件的相对路径及补丁片段。卸载不再猜测 `stm32f4xx_it.c`，只撤销有归属、能唯一定位的片段。无关用户修改保留；工具片段已被编辑或定位不唯一时，停止卸载。
- 老版本记录若缺少对既有源码的补丁归属，会拒绝自动卸载，不猜测恢复内容。可先检查事务回滚预览，或备份后人工迁移；回滚可能覆盖事务之后的用户修改。
- 写入前重新解析 XML，验证规划结果、Target 身份及未选 Target；发现外部修改工程文件时停止覆盖。XML 仍使用 ElementTree 序列化，**不是逐字节最小差异写入**。
- 下载、事务规划/复制/哈希/写入、卸载、回滚与 Keil 编译在后台工作线程执行。日志、进度和差异确认均回到 Tk 主线程。忙碌期间限制重入、切换语言和关闭；不提供写入中强制取消，差异预览仍可取消。
- 下载最终失败提示直接给出“设置镜像/代理或选择本地源码”的处理方法。翻译反向表出现重复值时会明确报错，不再静默丢失映射。

## 源码结构

`keil_port_tool.py` 保留现有入口、CLI 和兼容函数导出；新增 `kps_core/`：

- `source_patches.py`：不依赖 GUI 的启动/异常文本补丁。
- `ownership.py`：源码补丁记录与保守撤销。
- `runtime.py`：线程隔离的操作回调上下文。
- `errors.py`：共享错误类型。

源码使用者必须保留 `kps_core` 文件夹，不能只复制入口 PY。纯核心模块可以单独 import，不启动 GUI，也不加载下载配置。GUI、XML 与各组件尚未全部拆分；后续按测试覆盖逐项迁移，不做一次性大改。

## 本轮验证

新增回归覆盖：未知/半完成启动补丁、注释伪匹配、异常处理用户逻辑、非 F4 文件名卸载、用户编辑保护、XML 外部修改/未选 Target、翻译冲突及 LwIP 文件归属。GUI 使用真实 Tk 事件循环检查后台心跳、确认返回、错误传播、重入和关闭保护；不是仅检查函数存在。

实板为既有普中 STM32F407ZGT6 / ARMCC 5.06 update 7 / UART2：

- 新生成 RT-Thread 5.2.2 内核：烧录校验后复位 3 次，每次 23 项通过，含 2,000 条队列消息、浮点上下文、软件定时器及 HAL/RTOS 时基。
- 新生成 FreeRTOS 10.5.1 + CMSIS-V2：烧录校验后复位 3 次，每次 95 次检查通过，含任务通知、队列、信号量、互斥锁、定时器、消息/流缓冲区、任务生命周期和堆回收；随后持续传递消息，错误计数为 0。
- FreeRTOS 测试构建为 0 错误/0 警告；RT-Thread 有 2 条既有上游 AC5 警告，未隐藏。
- RT-Thread + LVGL 8.4 + CMSIS-DSP + RTT 的新组合工程已烧录校验并复位 3 次，每轮 19 项串口检查通过、DMA 错误为 0。全量构建 0 错误/25 条第三方源码警告。用户已确认当前屏幕无缺陷，目视验收独立于帧计数。
- 最终软件回归 18 个独立测试脚本通过，含真实 Keil 构建。候选 EXE 从中文带空格路径解压启动，仅保留 System32 在 PATH：实际点击扫描、取消预览、确认写入临时工程、中英文切换和英文离线指南正常；磁盘 manifest/备份已核对。此环境仍装有 Python，不等于干净虚拟机验收。

原始日志和设备标识留在本地，不进入公开源码 ZIP。发布验收表补充最终组合显示测试与解压 EXE 测试结果。

## 仍不能据此宣称

RC3 补测了本板的 FatFS/LittleFS 三种模式、原生 USB 及 FreeRTOS/RT-Thread 网络适配，
并完成一次真实断电后的存储只读校验，详见[硬件验证矩阵](HARDWARE-MATRIX.zh-CN.md)。
这些测试仍不覆盖所有 MCU/编译器/组件组合。USB Host、IPv6/MQTT/TLS、所有屏幕驱动、
MDK6/CMSIS Solution、RTE/Pack 管理和 CubeMX `.ioc` 同步不因此获得认证。
大规模文件树插入等部分 UI 操作仍可能短暂停顿；没有全过程强制取消功能。
干净 Windows（完全未装 Python/Git）的独立验收仍是发布清单事项。

运行回归并保留每个进程输出：

```powershell
python tools/run_tests.py test-results
```

输出目录必须不存在；CI 同样保留失败、超时和 Tk 线程错误日志。测试通过不等于可以忽略硬件接线与移植后指导。
